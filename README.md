# PrismKit（棱镜）

一个面向 Minecraft 特效开发的通用工具库模组。

## 当前开发内容

### 贝塞尔曲线工具

- [x] 贝塞尔曲线基础算法
- [ ] 贝塞尔曲线显示器
- [ ] 实时编辑贝塞尔曲线

### PrismSystem 特效系统

正在开发中。

## 版本与运行环境

- Minecraft 1.21.1
- NeoForge 21.1.249
- Java 21

本分支使用 NeoForge 和 ModDevGradle 构建。运行 `./gradlew build`（Windows 使用 `gradlew.bat build`）后，模组 JAR 位于 `build/libs/`。
